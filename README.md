# Ansible Lab — управление серверами как кодом

Лаба по Ansible: от SSH-ключей и ad-hoc до ролей, Vault и обновления приложения без простоя. Сквозной проект — выкатка **CoffeeShop** на «серверы» (контейнеры с `sshd`).

**Статус: ⚪ заготовка (репозиторий создан 11.10.2026). Методички нет, кода нет, ничего не проверялось запуском: есть только план [`ansible_lab_plan.md`](ansible_lab_plan.md).**

## Что по плану

- 10 сессий, ~40 часов, по ~4 часа каждая; в каждой — «Слова сессии», шаги по стандарту подробности («каждое слово объяснено», «где мы и что должно быть», «если не получилось»), «Сломать → починить», критерий приёмки.
- Режим: продолжение Docker-лабы (разворачивает её образ и compose) **или** самостоятельная (`starter/` с образом и `compose.yaml`). Реальный сервер владельца не используется.
- Версии и поведение инструментов в плане **не проверены прогоном**; пометки «сверьтесь» стоят там, где версия может измениться.
